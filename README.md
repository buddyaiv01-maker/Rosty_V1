# Rosty — Liquid Glass

A standalone streaming-platform UI in the **Liquid Glass** design language — translucent frosted surfaces, fluid depth, and an animated floating pill nav — extracted from the [Rosty](https://github.com/buddyaiv01-maker/Rosty) UI showcase.

**Live:** https://buddyaiv01-maker.github.io/Rosty_V1/

Real titles, posters, synopses, cast, and ratings sourced from [OMDb](https://www.omdbapi.com/), stored locally in `public/data/`.

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` build and deploy automatically to GitHub Pages via `.github/workflows/deploy.yml`.
